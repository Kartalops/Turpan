# NextSaaS - Authentication & Billing Platform

A production-ready Next.js SaaS application with full authentication, billing, and admin dashboard.

## Features

- **User Authentication** — Email/password login with JWT tokens, session management, and password reset
- **Billing & Subscriptions** — Stripe-powered subscription management with plans, upgrades, and invoices
- **Admin Dashboard** — Full admin panel with user management, analytics, and billing controls
- **API Routes** — RESTful API endpoints for all core features
- **Real-time Events** — WebSocket support for live notifications

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

```env
DATABASE_URL=
STRIPE_SECRET_KEY=
JWT_SECRET=
ADMIN_EMAIL=
```
